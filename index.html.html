Cài đặt API Keys cho các Model AI

🤖 OpenAI (ChatGPT)

🔮 DeepSeek

Base URL tuỳ chọn — để trống dùng mặc định. Muốn hỏi về rig + animation pro thì chọn 🔮 DeepSeek ở danh sách model.

⭐ Google Gemini

🚀 OpenRouter

Dùng 1 key cho nhiều model (GPT-4o, Claude, Gemini, DeepSeek…). Cần có ít nhất $1 trong tài khoản để gọi được model trả phí.

🌐 xKiro

Text + image (api.xkiro.com/v1). Đặt XKIRO_API_KEY trong .env để dùng qua server.

🎨 APInex

Text + image (api.apinex.bond/v1). Đặt APINEX_API_KEY trong .env.

🛰️ AgentRouter

Một key dùng cho gpt-5.6-sol · gpt-6-astra · gpt-6.1-sol. Để trống base URL nếu dùng mặc định. Khi chạy qua dev_server.js, key có thể nằm trong file .env (AGENTROUTER_API_KEY).

🌙 Moonshot AI (Kimi)

Hỗ trợ model Kimi-K2-0905, Kimi-Latest. Base URL tuỳ chọn — để trống dùng mặc định.

🧠 Zhipu GLM

Tất cả keys được lưu trong localStorage của trình duyệt này, không gửi đi đâu ngoài API của các provider tương ứng.
